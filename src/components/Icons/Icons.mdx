# Icons

Every icon the app uses, with the files that use it (paths relative to `src/`).
Before adding an icon, look here first: if one already means what you need, use it rather than a
near-identical second one.

The list is generated from the code each time Storybook starts, so a new icon shows up after a restart.

## Material icons

Imported from `@mui/icons-material`, e.g. `import CloseIcon from "@mui/icons-material/Close"`.

<Grid>
  {Object.entries(muiIcons).map(([name, Icon]) => (
    <Cell key={name} icon={<Icon />} name={name} files={muiIconUsage[name]} />
  ))}
</Grid>

## Image icons

Files in `public/static/icons/`. A name built at runtime is not found by the scan: the
`A1`…`C2-level-icon.png` files are used by `videos/VideoStatInfo.js` as `` `${cefr_level}-level-icon.png` ``.

<Grid>
  {Object.entries(staticIcons).map(([file, files]) => (
    <Cell
      key={file}
      icon={<img src={`/static/icons/${file}`} alt="" style={{ maxWidth: "32px", maxHeight: "32px" }} />}
      name={file}
      files={files}
    />
  ))}
</Grid>
